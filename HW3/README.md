Use make and then run ./test. This will bring up and interactable menu.
1. Insert/Update a key value. You insert a new key-value pair or update one.
2. Find a value by key. Put in a word and it will give you the pair.
3. Delete a key. Deletes the key
4. Print tree. Prints the tree in order
5. Find the minimum key value. Finds the smallest key value in the tree.
6. Find the maximum key value. Finds the largest key value in the tree.
7. Save the tree to file. Asks user to put a file in and saves the tree to that file
8. Process the file. Takes in a file and figures out the data, creating the tree.
9. Exit. Exits the program

The purpose of this project was to make and implement a custom binary search tree class. We find the data and key, finding what is repeated from a text file.

I had a lot of issues with the format of this one. I would get one thing to work and then would break it with something else. Finally I was able to get everything to work how I had intended. This was probably the hardest assingment I've done. But i enjoyed the challenge.
