/** The code demonstrates some of the capabilities of using a linked list. These include:
Reading a file
Writing to a file
Looking up a user via name
Looking up a user via phone number
Deleting a user
Adding a user
Printing the phonebook

Upon initiating the make commmand, the code will compile with the executable ./test
When executed the user is prompted with 8 choices
1. User is prompted what file to read from.
2. User is prompted what file to write to.
3. Prints the current phonebook.
4. Prompts the user to input a name and returns the phone number for that user.
5. Prompts the user to input a phone number and returns the name for that user.
6. Prompts the user to give a name and phone number and adds the user into the list alphabetically.
7. Prompts the user to give a name and deletes the user from the phonebook.
8. Exits the program.

Provided with the program is a phonebook.txt file that contains a list of test names and numbers.
Any .txt can be used as long as it follows the following format:

FirstName LastName
Phonenumber

*/
